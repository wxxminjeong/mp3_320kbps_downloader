# MP3 320kbps Downloader

YouTube URL to 320kbps MP3 downloader.

## Usage
Download `MP3_320kbps_Downloader.exe` from Releases.

## Developer Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Place `ffmpeg.exe` in the same folder as `main.py`.

3. Run:
```bash
python main.py
```
